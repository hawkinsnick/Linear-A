# 2.3.0 — executable blind-calibration gate

2.3 converts the planned Linear B calibration from prose into an executable,
checksum-gated blind protocol. The exact DĀMOS-v2 input is required. The detector-facing
stage cannot read morphology or syntax labels and writes frozen predictions before any
gold reveal.

The input bytes could not be transported into this sandbox, so 2.3 reports no
calibration performance. This is a ready experiment, not a successful experiment.
