# Contributing

This project distinguishes observation from interpretation.

## Before adding data

- Record the exact source.
- Record the source version/date where possible.
- Check copyright and license status.
- Do not present a proposed reading as an established reading.
- Prefer structured fields over prose when the information can be queried.

## Confidence vocabulary

Use one of: observed, secure, probable, possible, speculative, contested, rejected.

These labels describe the status of a claim, not whether we personally endorse it.
