# Data Policy — 0.4 additions

- Observation before interpretation.
- Source representation before normalization.
- Preserve source ID, source-local record, version/retrieval context, license/rights, transformation history, and provenance where available.
- A graphic variant is not automatically a separate sign, scribal hand, linguistic distinction, or chronological distinction.
- Store numeral form before value; add values/units/functions only when supported.
- Do not infer numeral values solely from Linear B analogy.
- Source disagreement is data and must not be silently resolved.
- Derived fields should be reproducible from preserved source-facing fields and documented transformations.
- Third-party rights and licenses travel with source-derived records; re-encoding creates no new unrestricted grant.
