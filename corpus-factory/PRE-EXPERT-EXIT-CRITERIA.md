# Pre-expert exit criteria for all 18 language repositories

Independent expert review is the final scholarly acceptance step, not a substitute for source acquisition, reconciliation or software repair. These criteria define a reviewable package, not a decipherment or independently certified corpus.

1. Declare finite source/edition/date-bounded populations and enumerate every included, missing, excluded, duplicate-candidate and disputed record. Keep catalogue entries, objects, surfaces, text rows, reading versions and occurrences separate. Open-world discovery prevents a terminal count for the entire language.
2. For every existing assertion, provide an exact source locator, authority/dependency, inspection status, uncertainty and rights basis. Pursue lawful accessible primary sources before assigning an expert-only stopping disposition. Record unavailable primary text separately from expert adjudication.
3. Collate acquired reference strings against primary editions where possible. Preserve source literals, damage, unidentified marks, restorations, alternatives, segmentation and editorial conventions. Numeric agreement does not certify the ancient sign or create an independent witness.
4. Reconcile identifiers, source numbering and inventory aliases using explicit source evidence. Preserve uncertain object joins and core/candidate/quarantined membership. Cross-repository overlap and shared source lineage must not become independent objects/witnesses.
5. Deliver those qualifications with the assertion in dossiers, queries, downloads and applicable interchange. An apparatus file merely existing elsewhere is insufficient. Different views must round-trip assertions and provenance without silent certainty or identity promotion.
6. Make licensing component-specific, validate exports against applicable actual standards, and bind builds/checks to their precise source and published artifact revisions. Green software checks are not epigraphic acceptance. Prevent publication races and stale generated authority hashes.
7. Prepare a precise expert decision queue with inspected evidence, unresolved question, competing accounts, effect on downstream claims and acceptance criteria. Complete independent nonexpert work before handoff. Maintain all gates that require expert judgment, accepted readings or calibration evidence.

A repository reaches this target only within explicitly declared work/edition scopes. Missing legal source access, permission decisions, unavailable images and unavailable calibration datasets are acquisition dependencies; they must not be relabelled as human-review completion or ignored. Newly accessible authoritative evidence reopens source work. A legitimate final expert packet may still contain unresolved scholarly alternatives and explicitly unavailable source evidence, but its readiness claim must name those limitations.

The collection currently has mature shared governance and inventories but uneven source depth. Priority-review items 1–3 are actionable integrity work before expansion. Source bridges and recorded conflicts should then be worked through as far as available evidence permits. Broader lawful coverage follows, with independent acceptance last. Undeciphered scripts cannot acquire accepted phonetic values or translations through engineering alone. Linear B's aligned linguistic gold and graphical baseline remain separate calibration prerequisites.
