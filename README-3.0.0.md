# Linear A Open Corpus 3.0.0

3.0.0 is the first architecture-stable research-platform release.

It freezes a provenance-first evidence architecture, multi-witness epigraphic model, source-lineage accounting, Research API v1, experiment-gate model, Aegean cross-script interoperability contract, reproducible pipeline contract, statistical correction history and claim registry.

The release deliberately carries unresolved science forward: known-answer Linear B calibration has no scored result; the degraded-corpus experiment remains gated; and the prospective 2026 SigLA cohort has no outcome until pinned current bytes are materialized and compared.

The conservative historical positional result remains six of twelve candidates surviving the 1.7 document-cluster-bootstrap lower-bound criterion, pending execution and freezing of the 2.5 framework.

3.0.0 is **not** a decipherment release and is **not** a claim that the corpus is complete.
