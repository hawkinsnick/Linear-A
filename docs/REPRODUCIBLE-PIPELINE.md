# Reproducible research pipeline

Order:
1. validate canonical redistributable corpus tables;
2. validate witness/source-lineage invariants;
3. execute frozen statistical specifications when their declared inputs are present;
4. evaluate calibration/prospective gates;
5. audit claim registry against result/status files;
6. generate checksums/manifest.

A blocked external input is a successful scientific gate state when the prerequisite is genuinely unavailable. Pipeline automation must never substitute a different corpus merely to turn BLOCKED into PASS.
