State: **BASELINE_FROZEN**

This repository participates in the four-corpus evidence baseline. The baseline freezes what is actually measured before comparative experiments begin. Unknown, bounded, sparse and blocked dimensions remain explicit.

## Acquisition queue

1. Measure per-document context completeness: site, document class, source lineage, uncertainty and segmentation.
2. Export only dimensions with stable definitions for matched-degradation targets.
3. Preserve document-level clustering in all resampling.

## Family invariant

A metric becomes a cross-corpus experimental target only when its definition and provenance are compatible. Release/version progress never substitutes for evidence coverage.
