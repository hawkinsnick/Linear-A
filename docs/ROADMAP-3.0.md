# Roadmap to 3.0.0

3.0.0 is the first architecture-stable research-platform release.

## 2.6 — evidence API contract
Unify project-native tables behind a read-only, decipherment-neutral query contract. No canonical transcription is manufactured.

## 2.7 — reproducible pipeline
Define one command/workflow sequence for structural validation, witness validation, frozen multiverse execution, manifest generation and audits. Restricted/raw upstream bytes remain external inputs.

## 2.8 — prospective and calibration gates
Make blocked experiments first-class pipeline states. A missing authenticated corpus or gold layer produces BLOCKED, never a fabricated null/result.

## 2.9 — research-platform surface
Freeze adapter/plugin boundaries, machine-readable capability metadata and stable public data contracts. Interactive UI remains a downstream client, not part of corpus truth.

## 3.0 — architecture freeze
Audit provenance, rights, corrections, claims, schemas, executable gates and cross-script neutrality. 3.0 does not mean decipherment or corpus completeness.
