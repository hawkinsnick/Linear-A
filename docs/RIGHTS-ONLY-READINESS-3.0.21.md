# Rights-only readiness target — 3.0.21

The Linear A project has reached its **pre-expert machine-resolvable maximum** under the currently admitted evidence.

## What that means

The repository has working provenance, source-lineage, disagreement, review, API/browser, export, context-admission, scholarship-link, geospatial, accounting/metrology and analytical machinery. Remaining physical-reading disagreements cannot be strengthened by more software applied to the same source ancestry.

The residual evidence-growth gates are:

1. **GORILA / EFA:** project-specific refusal blocks systematic transcription, structured/machine-readable derivatives and visual redistribution.
2. **Raison–Pope:** systematic reconciliation remains blocked pending lawful access and rights appropriate to the intended derivative use.
3. **PA-I-TO / other object-level datasets:** richer imaging/model ingestion requires compatible permission.
4. **Independent epigraphic confirmation:** requires a genuinely independent rights-compatible witness, lawful object-level evidence, or human object review. This is downstream of source access; it is not an unfinished corpus-engineering feature.
5. **Prospective experiment:** remains sealed until an admissible independent input/gold basis exists. Software cannot manufacture independence.

## What is not a blocker anymore

Missing schemas, provenance machinery, disagreement representation, researcher API/browser, review packaging, context admission rules, basic interoperability/export, basic metrology checks, and sequence-analysis tooling are not blockers to receiving new evidence.

Further UI/statistical/export improvements remain worthwhile, but they are **optional depth**, not prerequisites for incorporating lawful independent evidence.

## Claim discipline

“Rights-only readiness” does **not** mean the corpus is a completed critical edition or that expert validation is unnecessary. It means that the project has removed the machine-resolvable obstacles that would prevent lawful independent evidence from being admitted, compared, reviewed and exported. Stronger epigraphic claims still require stronger evidence.
