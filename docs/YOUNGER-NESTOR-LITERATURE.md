## How researchers and AI assistants should use it

Search the JSON by author, title, record ID or scope. Follow the original resource and publication links. Cite the publication and the discovery source separately. A Nestor listing verifies a bibliographic lead, not the article's findings or peer-review status. Titles using words such as “grammar”, “suffixes” or “prefixes” do not establish those claims in this corpus.

Younger's Kansas page failed direct web retrieval in this check; Cambridge's resource description confirms the link, not its current contents. The 2015 roundel chapter is a secondary contents-page lead. The encoding proposal's header was inspected; no character table or inscription payload is imported. The Nestor 53.9 entries use both printed pages and PDF ordinals. Selected records are neither a systematic search nor proof of literature exhaustion.
