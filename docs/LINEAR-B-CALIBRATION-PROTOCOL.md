# Frozen Linear B calibration protocol

1. Acquire the checksum-pinned DAMOS-derived corpus under CC BY-NC-SA 4.0.
2. Verify SHA-256 before parsing.
3. Extract source-defined word transliterations without morphology labels.
4. Freeze detector outputs.
5. Only then join known Mycenaean morphological analyses.
6. Report recovery, false positives, power, and failure modes.
7. Do not tune the detector after morphology labels are revealed without declaring a new experiment.

This release records BLOCKED rather than replacing the intended corpus with an easier proxy.
