# 1.0 Release Criteria

Combined Corpus Research AI 1.0 is an orchestration-contract release.

## Required
- [x] Explicit corpus-project registry
- [x] 11 initial corpus projects registered
- [x] Individual-skill authority rule
- [x] Cross-corpus comparability gate
- [x] Evidence-class discipline
- [x] Provenance/source-independence rule
- [x] Rights firewall
- [x] Staleness behavior
- [x] Undeciphered-script safeguards
- [x] Nontechnical quickstart
- [x] Vendor-neutral adapter guidance
- [x] Structural validator
- [x] Adversarial conformance specification

## Not claimed
1. 1.0 does not certify completeness or correctness of member corpora.
2. 1.0 does not establish relationships among scripts/languages.
3. 1.0 does not mean every third-party AI model has passed behavioral tests.
4. 1.0 does not override member-corpus scientific gates or licensing.
5. A future dedicated repository may host this package; relocation does not change its scientific contract.


## 1.1 Pre-Expert Maximum integration

The orchestrator now recognizes member-level Pre-Expert Maximum contracts. These contracts distinguish remaining deterministic/source work from decisions reserved for human specialists; they never imply expert validation or corpus completeness.
