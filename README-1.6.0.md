# 1.6.0 — context-conditioned structural release

The twelve frozen boundary signals are now joined to source-explicit document type
and period metadata without assigning administrative or lexical meanings.

For strata with at least ten source-word tokens, the release records candidate edge
rates and context breadth. **2 / 12**
candidates have at least two edge hits in two or more document types; **9 / 12**
do so across two or more period labels.

This is descriptive conditioning only. A difference between tablet types or periods
is not treated as a semantic, functional, chronological, or grammatical explanation.
The next inferential gate requires document-level resampling and adequate stratum sizes.
