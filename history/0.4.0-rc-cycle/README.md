# Historical 0.4.0 RC cycle

This directory intentionally preserves the project's local release-candidate archaeology.

These are **historical snapshots**. Later RCs correct or supersede earlier interpretations. They are useful for reproducibility and for seeing how failed models were tested and rejected.

Included: RC1–RC11 and RC15. Raw SigLA payloads, GORILA plates/text, images, PDFs and third-party source code remain excluded.

| RC | Main purpose |
|---|---|
| RC1 | reconciliation baseline and unresolved-case register |
| RC2 | conflict reclassification and sensitivity branches |
| RC3 | materiality/KN Zc6 punctuation and branch-aware analysis |
| RC4 | structural computational baseline |
| RC5 | adjacency null model, position/site/bootstrap controls |
| RC6 | motif/network architecture |
| RC7 | variable-slot/template families |
| RC8 | context controls; exposed confidence-bridging problem |
| RC9 | boundary forensics; rejected integer-enum interpretation |
| RC10 | candidate f3 coordinate model; KN Zc6 local validation |
| RC11 | f3 anomaly/wrapper investigation |
| RC15 | final 0.4 evidence-tiered f3 policy |

Do not read an early RC claim as current methodology without checking later RCs and the consolidated research history.
