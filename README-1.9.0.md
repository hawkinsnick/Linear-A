# 1.9.0 — scholarly interoperability release

Version 1.9 freezes how this project talks about other people's research.

External scholarship is not ranked against this project. Comparisons must identify
differences in evidence, corpus and operationalization. Non-reproduction under our
pipeline is reported as such, not converted into a claim that another scholar's
broader interpretation has been disproved.

The same courtesy does not weaken our internal audit: errors in this repository remain
errors and are documented directly.
