# 2.2.0 — re-evaluation gate

The intended pseudo-Linear-A experiment is **not run** because its prerequisite
known-answer Linear B baseline has not yet been executed. Advancing anyway would turn
a useful control into theater.

The postmortem therefore changes the evidence hierarchy:

- decoder/source-word structure: retained;
- `f3` semantics: quarantined;
- 12-candidate set: retained as a frozen adversarial screen, not a linguistic set;
- 1.3: retained as cross-representation, not independent epigraphic replication;
- **1.7 document-cluster result is promoted as the more conservative candidate filter:
  6/12 retain a lower 95% bootstrap enrichment-z bound above 1.96**;
- edge graph: retained as structural evidence;
- Linear B calibration: highest-priority open experimental gate;
- pseudo-Linear-A degradation: blocked until that gate is passed.

This release is deliberately allowed to contain a blocked experiment. The purpose of
versioning is to preserve what the evidence permits, not to guarantee a positive result.
