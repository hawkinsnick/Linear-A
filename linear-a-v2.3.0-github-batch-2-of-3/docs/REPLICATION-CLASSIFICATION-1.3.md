# Replication vocabulary

`same-source robustness`: alternate analyses over the same source representation.

`cross-representation replication`: the signal reappears in a separately encoded/
segmented corpus representation, but the representations share important upstream
epigraphic sources.

`independent epigraphic replication`: requires genuinely independent readings or
primary-object/plate adjudication sufficient to break the shared-source dependency.

Version 1.3 reaches the second level, not the third.
