# 1.0 limitations

The corpus is small, fragmentary, source-dependent, and predominantly administrative.
The project relies substantially on SigLA for its source-defined word layer.
Same-source robustness is not independent replication.

The twelve positional candidates remain vulnerable to editorial segmentation,
corpus composition, unmodeled scribal/contextual structure, and the possibility
that positional concentration has non-morphological causes.

Canonical source-explicit site mapping is not yet released. The legacy
`site_group_heuristic` is not geography.

No claim in 1.0 identifies the underlying Minoan language or translates Linear A.
