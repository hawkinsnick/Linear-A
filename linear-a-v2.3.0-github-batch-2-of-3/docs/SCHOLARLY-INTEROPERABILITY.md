# Scholarly interoperability and disagreement policy

This project is intended to complement, not rank, existing Linear A scholarship.

## External claims
External scholarly claims are stored as attributed claims with their authors'
terminology, corpus, date, evidence and operational definitions where available.
They are not silently rewritten into this project's ontology.

## Comparison vocabulary
Use:
- `reproduced_under_current_operationalization`
- `not_reproduced_under_current_operationalization`
- `directionally_consistent`
- `representation_sensitive`
- `source_conflicted`
- `not_comparable`
- `insufficient_evidence`

Avoid `wrong`, `debunked`, `disproved`, or similar language unless the claim is a
precisely falsifiable proposition and the relevant evidence genuinely adjudicates it.

## Method disagreement
A different result can arise from corpus coverage, transcription, segmentation,
uncertainty treatment, sign normalization, sampling unit, null model, multiple-testing
correction, or the substantive question being asked. Record these before interpreting
a disagreement.

## Corrections
Errors in this repository should be called errors and corrected transparently.
Potential errors in another scholar's corpus or argument should be described narrowly,
attributed, and—where practical—shared constructively with the researcher before being
used rhetorically.

## Human scholarship
Statistical non-reproduction is evidence about a specified model and dataset. It is
not a judgment of a researcher's competence, care, or contribution.
