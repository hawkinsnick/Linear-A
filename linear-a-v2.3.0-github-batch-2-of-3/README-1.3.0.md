# 1.3.0 — cross-representation replication release

The twelve frozen positional candidates were tested against the current pinned
`mwenge/lineara.xyz` `LinearAInscriptions.js` representation.

After retaining multi-sign Unicode Linear A word tokens:
- 1402 token occurrences
- 1009 unique types
- **12 / 12** frozen candidates reproduce their enriched
  boundary direction at type-level z > 1.96.
- weakest type-level z: 2.24.

This is **cross-representation replication, not independent epigraphic replication**.
The comparison corpus principally derives from GORILA/Douros, so shared upstream
readings can generate agreement. The result nevertheless shows that the twelve-signal
pattern is not unique to SigLA's serialized Word-object representation.
