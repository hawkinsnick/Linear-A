# Linear A Open Corpus 1.0

Version 1.0 freezes the first complete research architecture of the project.

It provides:
- provenance-first sign/document/source schemas;
- explicit source/license tracking;
- a reproducible SigLA Marshal decoding architecture;
- same-snapshot executable cross-validation;
- source-specific reconciliation and uncertainty records;
- explicit SigLA Word-object extraction independent of unresolved `f3`;
- source-word structural analyses with null models and adversarial controls;
- per-candidate evidence dossiers;
- a claim registry that records corrections, open blockers, and prohibited overclaims.

## The strongest current result

Twelve sign/position combinations survive the project's 0.8 adversarial screen.
All twelve also survive 0.9 type-level Holm correction and a random-internal-
position negative control.

They are **robust structural positional candidates**. Version 1.0 does not call
them prefixes, suffixes, morphemes, grammatical markers, phonotactic rules, or
decipherments.

## What 1.0 deliberately leaves open

- independent identity-level replication of the twelve candidates;
- known-answer Linear B calibration of this exact detector;
- canonical source-explicit site mapping;
- global semantics of `f3`;
- primary plate adjudication for remaining epigraphic conflicts;
- linguistic interpretation.

A stable release is not a declaration that the script has been deciphered.
It means the project's data model, provenance rules, correction history,
reproducible structural results, and limits are sufficiently explicit to serve
as a research foundation.
