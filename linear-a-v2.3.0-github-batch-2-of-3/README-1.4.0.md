# 1.4.0 — calibration acquisition / falsification release

The known-answer Linear B experiment remains deliberately blocked at full-corpus
materialization. The public DĀMOS interface and JSON tablet endpoints were independently
verified, but the frozen checksum-pinned derivative could not be downloaded in this
execution environment.

No miniature corpus, hand-picked tablets, or synthetic substitute was promoted to a
calibration result. This preserves the blind protocol for a later environment that can
materialize and hash the complete corpus.

The release nevertheless advances the project by distinguishing:
1. frozen derivative identity;
2. direct-current DĀMOS API data;
3. calibration outputs.

They must never be silently mixed.
