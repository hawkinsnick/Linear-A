# 1.5.0 — edge-alternation structure

This release asks a stricter question than positional enrichment: when a frozen
edge-enriched sign is removed from the relevant edge, is the remainder itself an
attested SigLA-defined word type?

Across the complete source-word type inventory there are **651** attested
one-edge-removal pairs in **4** connected components. **11 / 12**
frozen positional candidates participate in at least two such type pairs.

These are distributional form relations. They are not called stems, affixes,
inflectional paradigms, derivation, or grammar.
