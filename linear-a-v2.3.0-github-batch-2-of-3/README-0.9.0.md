# Linear A Open Corpus — 0.9.0-local

0.9.0 is the calibration and evidence-dossier release.

The twelve strict 0.8 positional candidates are frozen before external identity
comparison and receive machine-readable dossiers containing every supporting
source-word token, document, exact type, context fields and robustness metrics.

The release adds a type-level candidate multiverse with Holm correction and an
internal-position negative control. External literature/projects are recorded
as methodological comparators only where the accessible evidence does not
support exact candidate-identity replication.

Known-answer Linear B calibration is explicitly BLOCKED rather than simulated:
this workspace does not yet contain a license-reviewed Linear B word corpus
aligned to the exact 0.9 positional test.

No candidate is assigned an affix, morpheme, grammatical, semantic or phonetic
interpretation.
