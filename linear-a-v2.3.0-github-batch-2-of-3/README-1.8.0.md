# 1.8.0 — edge-alternation null

The 651 attested edge-removal relations are tested against a type-level within-word
shuffle null. Observed directed edge-removal pairs: **651**; null mean **587.2**
(SD 8.5); empirical upper-tail p **0.000999**.

The null asks whether the form graph contains more one-edge deletion relationships
than expected after destroying sign order while preserving each type's length and
sign inventory. It does **not** test whether those relations are morphological.
