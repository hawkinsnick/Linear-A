# Linear A Open Corpus — 0.4.0-rc1-local

This is a local pre-publication release candidate. Nothing in this tree has
been published to GitHub.

## What RC1 establishes

- The supplied SigLA snapshot is structurally reproducible: 802 documents,
  5,144 attestations, with zero semantic differences in the independent
  executable comparison across 46,296 fields.
- AB21/AB22 is represented as a source-specific systematic disagreement with
  third-witness triangulation, not a silent global rewrite.
- Comparator convention noise is separated from genuine epigraphic conflicts.
- Reading certainty, provenance, source disagreement and visual-evidence status
  are explicit dimensions.
- Numeral, word-boundary and sign conflicts remain branchable rather than
  silently normalized.
- Visual evidence is graded by type: actual-object photograph, plate/drawing,
  occurrence tracing, transcription witness, or unresolved.
- Palaeographic variants are not invented from canonical sign IDs.

## Current unresolved research queue

RC1 retains 15 high-priority unresolved cases: one numeral conflict, eight
remaining sign/compound-sign issues after ARKH1b gained provisional support,
five word-boundary issues, and the fraction-K metrological disagreement.

HT113 and HT4 are no longer counted as bare numeral-reading conflicts because
the compared values occur at different positions in the current document
records. HT10a has provisional support for 14. ARKH1b has provisional support
for PA-RE. AP Za 2 has provisional support for -NU.

## Distribution

No raw SigLA database, SigLA drawing corpus, GORILA plate, van Soesbergen book
text, or other third-party corpus payload is bundled.
