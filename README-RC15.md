# Linear A Open Corpus — 0.4.0-rc15-local

RC15 freezes the 0.4.0 release-candidate cycle.

The cycle does **not** claim to decode SigLA `f3`. Instead, RC12–RC13 establish
an evidence-tiered representation that preserves wrapped/direct topology,
coordinate-like values, anomalies, and uncertainty without forcing them into a
single semantic schema.

RC14 freezes which computational results remain valid, exploratory, or
superseded. RC15 performs the release audit and records the remaining blockers
for a final 0.4.0 release.

Nothing has been published to GitHub.
