# Linear A Open Corpus 2.4.2

2.4.2 establishes the multi-witness epigraphic layer.

The release separates canonical document identity from source-specific assertions, source ancestry/independence, and explicit disagreements. Agreement is counted by evidential lineage rather than by the number of digital representations.

This prevents two websites that reproduce the same upstream edition from masquerading as two independent epigraphic confirmations.

The infrastructure is complete; population from additional sources remains source-by-source and rights-aware. No majority-vote transcription is created, no linguistic reading is declared correct, and the frozen 2.3/2.4 experiments plus the 2.4.1 prospective cohort remain unchanged.
