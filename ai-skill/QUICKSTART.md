# Five-minute quick start

## Gemini

Upload the `ai-skill` folder or a ZIP whose top level is the contents of this folder. Gemini Skills recognizes a root `SKILL.md`. Add the recommended corpus files if they are not bundled in the release.

## ChatGPT

Create a Project or research chat, upload `SKILL.md`, `references/research-contract.md`, and the recommended corpus bundle, then tell ChatGPT: "Use SKILL.md as the governing research instructions for this project." Projects can retain uploaded files as project context.

## Claude and other assistants

If the product supports project knowledge, system/project instructions, files, or skills, use `SKILL.md` as the instruction file and upload the same recommended corpus bundle. If it has no skill mechanism, paste the Core rules from `SKILL.md` into its project/system instructions.

## First test

Ask:

> What can this corpus establish about Linear A, what can it not establish, and what current files define those limits?

A correct setup should distinguish corpus evidence and structural analysis from decipherment, mention uncertainty/provenance, and point to current-status/claim/errata evidence rather than confidently translating Linear A.
