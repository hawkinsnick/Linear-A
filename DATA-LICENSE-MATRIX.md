# Data License Matrix

## Project principle

The corpus is intended to be openly usable by everyone, subject only to rights and license restrictions that apply to upstream material we do not own.

We will make our own original contributions as open as legally possible. We will not relicense third-party material more permissively than its actual license allows.

## Current layers

| Layer | Intended treatment |
|---|---|
| Original project code | MIT License |
| Original schema and documentation | CC BY 4.0 or CC0 where appropriate |
| Original annotations/derived metadata | CC0 where legally appropriate |
| SigLA-derived dataset | Preserve SigLA's CC BY-NC-SA 4.0 terms and attribution |
| SigLA drawings | Preserve SigLA's CC BY-NC-SA 4.0 terms and attribution |
| GORILA-derived copyrighted text/images | Do not redistribute unless permission/license permits |
| Other third-party material | Preserve the original applicable terms |
| Public-domain material | Mark as public domain where verified |

## Attribution

SigLA states that its dataset and drawings are available under CC BY-NC-SA 4.0. See:
https://sigla.phis.me/about.html

The corpus should preserve SigLA attribution and the applicable noncommercial/share-alike requirements for SigLA-derived material.

## Important distinction

A transformation performed by this project does not automatically make the underlying upstream material ours. Every imported record should carry provenance and license information.

When rights are unclear, the default is do not redistribute the questionable material. Provide a source reference or an importer/retrieval instruction instead.

This document is a project data policy, not legal advice.
