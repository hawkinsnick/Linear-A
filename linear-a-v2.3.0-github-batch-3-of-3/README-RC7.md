# Linear A Open Corpus — 0.4.0-rc7-local
RC7 groups recurring 3–5-sign windows into frames differing at exactly one slot.

- candidate families: 440
- strong families (>=5 windows, >=3 documents, >=2 confident variants, >=4 confident windows): 224
- cross-site strong families: 166
- recurring-motif Hamming-1 edges: 102

A frame such as `A B * D` is a distributional variable-slot frame, not by itself
a paradigm, affix, word, or grammatical construction.

A 100-run document-preserving shuffle supplies a coarse null for the number of
recurrent variable-slot families. RC7 deliberately labels this coarse; stronger
nulls and document-type/boundary controls are future work.

Nothing has been published to GitHub. No raw SigLA attestation table or imagery
is redistributed.
